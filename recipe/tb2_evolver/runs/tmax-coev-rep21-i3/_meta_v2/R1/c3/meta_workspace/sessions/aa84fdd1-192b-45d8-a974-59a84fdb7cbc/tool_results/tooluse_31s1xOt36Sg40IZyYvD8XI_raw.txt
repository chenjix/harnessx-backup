"""LengthTruncationRecoveryProcessor for Tmax (and TB2-style) agents.

Closes a systemic failure mode: the model enters a *degenerate repetition
loop* — it keeps emitting the same narration with no tool call until the
response hits ``max_tokens`` (``finish_reason == "length"``). The run loop
then appends a passive "please continue" nudge, which re-primes the same
runaway generation. The cycle can burn an entire evolve round on one task.

This processor:
* collapses runaway assistant content (head+tail) after a length truncation
* replaces the passive continue nudge with a corrective "issue one Bash call"
  instruction (escalating on consecutive truncations)
"""
