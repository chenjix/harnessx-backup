38	class LoopDetectionProcessor(MultiHookProcessor):
39	    """Detect repeating step patterns using two parallel fingerprint strategies.
40	
41	    **Strategy 1 — exact** (name + inputs): high-precision, two-phase
42	    (warn then raise).  Catches identical tool calls repeated verbatim.
43	
44	    **Strategy 2 — name-only** (tool names, inputs ignored): catches semantic
45	    loops where the agent repeatedly calls the same *type* of tool with varying
46	    arguments (document-generation loops, infinite analysis sampling, etc.).
47	    Warn-only — never raises, because name-only matching is noisier and
48	    terminating on a loose signal would cause false-positive task failures.
49	
50	    Both strategies use the **consecutive run length** at the tail of their
51	    respective sliding windows, so interleaved steps break the count and avoid
52	    false positives on legitimate exploration.
53	
54	    **Compaction awareness**: fingerprint windows are cleared when a
55	    message-count drop of ≥ ``compaction_drop_threshold`` is detected in
56	    ``on_step_start``, preventing stale pre-compaction fingerprints from
57	    contributing to spurious loop counts.
58	
59	    Args:
60	        window_size:               Sliding window size for both strategies
