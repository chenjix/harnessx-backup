254	  triggers an advisory to run a real command or finish. Never raises; appends
255	  advisory to the tool result only (`event.messages` never mutated). Ignores the
256	  FunctionalVerifyGate keepalive tool; cooldown=4 prevents advisory spam.
257	- `config.yaml` — register the processor after `LoopDetectionProcessor`
258	  (window_size=8, repeat_threshold=5, empty_threshold=3, cooldown=4).
