You are a data engineer building a high-performance ETL pipeline. We have a C-based pipeline that processes streaming sensor data, handles anomalies, and computes similarity metrics. However, our current prototype is producing empty files because the initial data parsing and bootstrapping logic was never implemented.

Your task is to write a standalone C program `/home/user/etl.c` that completes the ETL pipeline requirements below. 

1. **Input Data**: 
A dataset is located at `/home/user/sensor_data.csv`. It has 3 columns (floating point numbers) and no header. 
Missing values are represented by the string `"NA"`.

2. **Missing Value and Outlier Handling**:
- Read the dataset. If a row has `"NA"` in *all* 3 columns, drop the row completely.
- For rows with partial `"NA"` values, replace the `"NA"` with the **mean** of all valid (non-NA) values in that specific column. (Calculate the mean of the column before replacing NA values, using only valid numbers).
- **Outliers**: After replacing missing values, if any value in the dataset is strictly greater than `100.0`, cap it exactly at `100.0`. If strictly less than `0.0`, cap it exactly at `0.0`.

3. **Reproducible Bootstrap Sampling**:
- Using the cleaned data (let's say it has `N` rows), take a bootstrap sample (sample with replacement) of size `N`.
- To make this reproducible, seed the random number generator strictly with `srand(42);`.
- Select row indices using `rand() % N` sequentially for `N` iterations. Add the selected rows to your bootstrap sample.

4. **Similarity Search (Centroid Distance)**:
- Calculate the centroid (the mean vector) of your bootstrap sample.
- Calculate the Euclidean distance between this centroid and a reference profile: `[50.0, 50.0, 50.0]`.

5. **Output**:
Print the results to a file named `/home/user/etl_report.txt` in exactly this format (rounding to 4 decimal places):
```
Centroid: <col1_mean>, <col2_mean>, <col3_mean>
Distance: <euclidean_distance>
```

**Execution**:
Write the code to `/home/user/etl.c`. Compile it into `/home/user/etl_bin` using `gcc -O2 /home/user/etl.c -o /home/user/etl_bin -lm`. Finally, execute `/home/user/etl_bin` to generate the report file.
