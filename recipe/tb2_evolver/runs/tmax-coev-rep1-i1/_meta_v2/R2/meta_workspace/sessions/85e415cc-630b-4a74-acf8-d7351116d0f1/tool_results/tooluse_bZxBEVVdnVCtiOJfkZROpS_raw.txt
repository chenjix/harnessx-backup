18	### Why
19	
20	R0 = 29/50 (0.58). The dominant failure mode is a max_tokens runaway
21	loop: the small model (Qwen3.5-9B) emits an enormous no-tool-call
22	narration turn (104K-329K chars) that hits the provider output cap.
23	The runloop (harnessx/core/runloop.py:734) then appends a passive
24	"Your previous response was cut off by the token limit. Please
25	continue from where you left off." nudge, which re-primes the exact
26	runaway generation while the 300KB blob pollutes the next context
27	window. The cycle burns steps/wall-clock (up to 74 steps, 964s) and
28	terminates in `exit_reason=error` with the required output file never
29	written. All 11 `exit_reason=error` tasks in R0 exhibit >=1 cut-off
30	nudge; 8 of them failed. Max assistant-turn size is cleanly bimodal:
31	passing cluster tops out at ~14.8K chars, runaway cluster starts at
32	104K — a 40K threshold sits in the empty band and cannot misfire.
33	
34	### Changes
35	
36	- `processors/length_recovery.py` — new `LengthTruncationRecoveryProcessor`
37	  (`MultiHookProcessor`). `on_after_model`: detect a no-tool-call turn
38	  with `finish_reason=="length"` OR `content>=40000` chars, collapse
39	  the blob to head+tail excerpt, arm an escalating nudge, count
40	  consecutive occurrences. `on_before_model`: inject exactly one user
41	  message redirecting the model to a single concrete Bash command
42	  (gentle first, forceful on repeat). Trigger keys only on structural
43	  signals — benchmark-agnostic.
44	- `config.yaml` — register the processor via absolute `file://` path,
45	  inserted after `TaskTimeReminderProcessor` and before
46	  `CompactionProcessor` (so the collapsed content reaches compaction).

64	### Uncertainty
65	
66	The nudge redirects the model to "one concrete Bash command"; if the
67	underlying task genuinely needs the model to reason more before
68	acting, the redirect could push a premature command. Mitigated
69	because the streak resets on any normal turn, so the model regains
70	freedom immediately after acting. Signal to watch: if the 2
71	loop-survivor passes regress or overall pass_rate drops, revert.
72	This exact processor lineage (tmax-ev9b50 R6) was built against the
73	identical bimodal signature, giving prior evidence it lands.
