93	### Why
94	
95	Assigned focus `task_000028_7fe033ac` failed with `status=error`, `reward=0`,
96	`elapsed_s=0.1`. The error is a Docker container-name Conflict raised by
97	`recipe/tmax_eval/docker_env.py::start_container` (line 124) — the container never
98	started, so the agent run loop never began and there is **no `.messages.json`** for
99	this task. This is not a model capability gap and not an in-loop harness deficiency;
100	it is an infrastructure flake in the eval driver. `start_container` names containers
101	`tmax-{task_id[:20]}-{int(time.time())}` with whole-second resolution; when tasks
102	launch in the same wall-clock second under parallel batch eval, names collide and the
103	daemon rejects the second `docker run`. The same flake hit 5 tasks this round
104	(task_000015, task_000028, task_000140, task_001653, task_001781) — all
105	`status=error`, `elapsed_s=0.1`, all with no episode log.
