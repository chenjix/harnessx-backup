2	"""SelfFabricatedTestGuardProcessor — a TB2 Control processor.
3	
4	Closes a recurring false-confidence failure shape: the agent builds a
5	deliverable (a detector / classifier / parser / transformer script), then
6	"validates" it *only* against test inputs it created itself by echoing a
7	value it just derived. Because the fabricated input contains the same
8	derived value the deliverable searches for, the test is a tautology — it
9	passes even when the derived value is wrong (e.g. a garbled OCR string) and
10	the ground-truth artifacts already present on disk go unexamined. The
11	verifier then runs the deliverable against the *real* inputs and it fails.
12	
13	This is content-agnostic and detects the *shape*, not any task:
14	
15	  1. Track every filesystem path the agent WRITES to during the run
16	     (heredocs, redirects, tee, sed -i) — these are "agent-fabricated".
17	  2. When a later Bash command RUNS the deliverable (invokes an executable
18	     script / `python3 foo.py` / `bash foo.sh` / `./foo`) and every
19	     file-path argument it references is an agent-fabricated path — i.e. it
20	     is being exercised exclusively against inputs the agent manufactured,
21	     never against a pre-existing task artifact — append a one-shot
22	     corrective note to the tool result.
23	
24	The note is append-only on the tool result (mirrors CustomEditToolProcessor),
25	never terminates, never mutates the system prompt, and fires at most

74	def _looks_written(cmd: str) -> set[str]:
75	    """Paths this command writes to (agent-fabricated candidates)."""
76	    if ">" not in cmd and "sed" not in cmd and "tee" not in cmd:
77	        return set()
78	    paths: set[str] = set()
79	    for pattern in (_HEREDOC_RE, _REDIRECT_WRITE_RE, _SED_INPLACE_RE, _TEE_WRITE_RE):
80	        for m in pattern.finditer(cmd):
81	            p = m.group(1).strip("'\"")
82	            if p and not _SKIP_PATH_RE.match(p):
83	                paths.add(p)
84	    return paths
