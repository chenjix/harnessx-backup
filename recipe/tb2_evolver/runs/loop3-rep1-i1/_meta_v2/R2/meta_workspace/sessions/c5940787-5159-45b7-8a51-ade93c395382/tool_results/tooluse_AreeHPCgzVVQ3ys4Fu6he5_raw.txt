421	
422	    This config contains only the processor pipeline and tool registry — no
423	    runtime-only slots (``sandbox_provider``, ``tracer``).  It can be saved to
424	    YAML via ``cfg.to_yaml_file(path)`` and evolved by the meta-harness.
425

427	
428	        base = make_tb2_harness_config(timeout_seconds=task_timeout)
429	        harness_config = base.copy(
430	            sandbox_provider=HarborSandboxProvider(environment, ...),

433	        harness = ModelConfig(main=provider).agentic(harness_config)
434	
435	    Args:
436	        timeout_seconds:  Task timeout disclosed to the model via
437	                          ``EnvironmentContextInjector`` and
438	                          ``TaskTimeReminderProcessor``.
439	        workspace_path:   Absolute path inside the container where task files live.
440	        output_limit:     Maximum characters captured per tool call (passed
441	                          through to ``HarborSandboxProvider`` at run time via
