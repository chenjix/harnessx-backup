20	### Why
21	
22	Assigned focus `task_000106_23215092` (data_querying) built a fully correct
23	Flask co-authorship-graph API: correct self-join SQL, networkx PageRank
24	summing to 1.0, exact JSON schema, 404 handling, all verified in-trajectory
25	with `urllib`. It still scored 0. The verifier's `test_final_state.py` fails
26	at **collection** with `ModuleNotFoundError: No module named 'requests'` — the
27	grading client library is simply absent from the container. Per the TB2
28	playbook, verifier files are injected *after* the agent exits, so the agent
29	cannot see that the test imports `requests`. This is a harness/verifier
30	environment gap, not a solution defect or a model capability gap. It recurs:
31	three distinct HTTP-service tasks across two domains and three languages
32	(Python/C++/Rust) all hard-fail with the identical `requests` collection error.
33	
34	### Changes
35	
36	- `processors/http_verifier_dep.py` — new `HttpVerifierDepProcessor`
37	  (`MultiHookProcessor`). Detects a server-start / port-bind in the agent's
38	  Bash commands (`_SERVICE_SIGNALS` regex: flask/fastapi/uvicorn/gunicorn/
39	  http.server/`app.run(`/`.listen(`/`--port`/`127.0.0.1:PORT` etc.), then on
40	  the next model turn injects exactly one reminder that the external test
41	  drives the service with `requests` and the agent must make `requests`
42	  importable (`python3 -m pip install requests`) before finishing. Fires once
43	  per task, only when a server was started.
44	- `config.yaml` — register `HttpVerifierDepProcessor` (`_order=91`) at the end
45	  of the pipeline, after `CustomSelfVerifyProcessor`.

63	### Uncertainty
64	
65	If a container has no outbound access at all, `pip install requests` could
66	fail; the reminder still costs little and the agent may find a vendored wheel.
67	If the model ignores the nudge, the fix does not land and we revert. If the
68	regex over-fires on a non-service command, the worst case is one wasted user
69	turn — measured by regressions on currently-passing non-service tasks in R2.
