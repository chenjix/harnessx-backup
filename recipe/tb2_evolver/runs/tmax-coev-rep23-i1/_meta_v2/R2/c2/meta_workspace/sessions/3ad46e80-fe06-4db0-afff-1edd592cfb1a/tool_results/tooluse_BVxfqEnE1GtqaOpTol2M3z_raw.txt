=== task ===
You are a Database Reliability Engineer managing a complex backup infrastructure. The metadata for all backups (Full and Incremental) across hundreds of databases is stored in a SQLite database located at `/home/user/backup_catalog.db`. 

Your task is to implement a C++ HTTP microservice that answers specific analytical queries about the backup state. You must also optimize the database schema to ensure these queries perform efficiently.

The SQLite database has the following table:
`CREATE TABLE backups (id INTEGER PRIMARY KEY, db_name TEXT, backup_type TEXT, parent_id INTEGER, size_bytes INTEGER, status TEXT, created_at DATETIME);`
`backup_type` is either 'FULL' or 'INC'. If it's 'INC', `parent_id` points to the immediately preceding backup in the chain (which could be an 'INC' or 'FULL' backup). If 'FULL', `parent_id` is NULL.

Write a C++ HTTP server listening exactly on `127.0.0.1:9090`. You may download and use the header-only `cpp-httplib` library for the HTTP server, and link against `sqlite3`. 

Your service must implement the following REST endpoints. All endpoints must require an `Authorization` header containing exactly `Bearer dbre-token-xyz123`. Return HTTP 401 Unauthorized if missing or incorrect.

1. **`GET /chain?id=<id>`**
   * **Goal:** Trace the lineage of an incremental backup back to its root Full backup.
   * **Implementation:** Use a Recursive CTE to traverse the `parent_id` relationships upwards until `parent_id` is NULL.
   * **Output Format:** A JSO
