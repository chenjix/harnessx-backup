======== task_001937_ac874115 ========
You are a performance engineer tasked with profiling and tuning a new distributed scientific simulation pipeline. 

The system uses a multi-service architecture located in `/app/`:
1. A Python-based numerical simulation worker (running on port 5001) that solves a PDE on a specified mesh grid and returns the simulation error, compute time, and the gradient of the error with respect to a tuning parameter.
2. An Nginx API gateway that is supposed to route traffic on port 8080 to the simulation worker.

Currently, the system is broken and unoptimized. Your tasks are:

1. **Fix the API Gateway:** 
   The Nginx configuration at `/app/nginx.conf` has a routing misconfiguration. Fix it so that requests to `http://localhost:8080/simulate` correctly proxy to the simulation worker. Once fixed, ensure both services are running (you can use `/app/start_services.sh` to restart them).

2. **Implement an Optimization and Convergence Profiler in Bash:**
   Write a Bash script at `/home/user/profiler.sh` that automates mesh refinement and parameter optimization. 
   - The API endpoint takes two query parameters: `grid` (integer) and `param` (float). 
   - It returns JSON in the format: `{"error": <float>, "grad": <float>, "time_ms": <float>}`.
   - Your script must implement a gradient descent optimization loop in Bash to find the optimal `param` that minimizes the simulation error for a given `grid` size.
   - Initial state: `grid=10`, `param=0.0`. Learning rate for gradient descent: `0.1`.
