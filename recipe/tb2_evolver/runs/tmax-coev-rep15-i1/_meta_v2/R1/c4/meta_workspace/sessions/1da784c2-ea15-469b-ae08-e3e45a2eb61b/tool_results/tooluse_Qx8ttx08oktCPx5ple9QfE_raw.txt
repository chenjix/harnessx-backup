20	### Why
21	
22	Assigned focus task_000015_89886d8d fails at final_pytest accuracy 0.3389
23	(< 0.98 gate). The task requires OCR-reading a dense multi-line URL→JSON schema
24	from `/app/routing_schema.png` with tesseract, then building a migration script
25	whose output keys must exactly match the golden schema. The agent's first
26	`tesseract … stdout` pass returned garbled text (`atalogyitem <item _id>…ordert
27	*<sort order»`); it then tried ad-hoc contrast/brightness/threshold enhancement
28	(one of which produced pure garbage), never upscaled the 800x400 image or varied
29	`--psm`/`--dpi`, gave up, and *guessed* the JSON key names — getting roughly one
30	of three route key-sets right (hence ~1/3 accuracy).
31	
32	The same mechanism recurs: task_000505_50b5162d (security) also fails after a
33	single tesseract pass on `/app/evidence.png` extracts a corrupted SSH key. By
34	contrast, the passing OCR tasks (000536, 001264, 001652) only needed a single
35	short grep-able token (an `EMP-…` id / a key), which survives noisy OCR — so they
36	never needed a robustness technique. The gap is method knowledge: when the first
37	OCR pass is garbled and the target is dense, upscale + sweep page-segmentation
38	modes and cross-check, rather than guess. I independently confirmed the schema
39	image is a clean, high-contrast target (light bg, ~2132 dark text px / 320000),
40	so the failure is low-resolution single-pass OCR — exactly what upscale + psm
41	recovers.
42	
43	A second, complementary gap: the agent tested migrate.py only on the 4-line
44	happy-path sample and stopped, despite the prompt warning of a "massive hidden
45	dataset of edge-case URLs" and to "handle URL decoding correctly" — no edge-case
46	self-verification before declaring done.

74	### Uncertainty
75	
76	The intervention assumes the model will actually apply the upscale+psm recipe
77	when it sees garbled OCR rather than ignoring the prompt section. If R2 shows the
78	two OCR tasks still failing at the same "guess the schema" step, the lever is
79	weaker than expected and a Control/Action approach (e.g. a helper the agent can
80	call) would be the next escalation. Watch for any regression on the currently-
81	passing short-target OCR tasks — none expected since the guidance is conditional.
